# Security Policy

## Supported versions

Security fixes are provided for the latest published Glace release.

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/scorpion7slayer/Glace/security/advisories/new).

Do not open a public issue for a suspected vulnerability. Include the affected Glace version, macOS version, reproduction steps, impact, and any suggested mitigation. You should receive an initial response within seven days.

Glace never needs passwords, recovery keys, or other private credentials in a report.
